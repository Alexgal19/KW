# Skaner KW

Програма для телефона. Фотографуєш бланк «Dowód wypłaty KW», а програма бере з нього прізвище та ім'я (поле «Komu») і суму (колонка «zł»). Потім складає таблицю виплат. Однією кнопкою завантажуються Excel із таблицею та один спільний PDF з усіма фото бланків. Якщо на одну людину є кілька бланків, суми додаються в один рядок.

Програма не залежить від Claude. Фото читає **Google Gemini** через твій власний безкоштовний ключ, а сама програма лежить на **GitHub Pages** (теж безкоштовно).

## Файли

| Файл | Що це |
|---|---|
| `index.html` | Програма |
| `manifest.webmanifest`, `sw.js`, `icons/` | Щоб програму можна було встановити на телефон як застосунок з іконкою |
| `lib/exceljs.min.js`, `lib/jspdf.umd.min.js` | Бібліотеки для створення Excel і PDF (працюють без інтернету) |
| `pracownicy.txt` | Список працівників (він уже вбудований у програму) |
| `src/skaner-kw.html` | Стара версія для Claude, для GitHub не потрібна |

## Крок 1. Отримати ключ Gemini (2 хвилини)

1. Відкрий https://aistudio.google.com/apikey і увійди через Google-акаунт.
2. Натисни **Create API key** і скопіюй ключ (починається з `AIza…`).
3. Ключ безкоштовний. Безкоштовного ліміту вистачає на сотні фото на день.

Важливо: у безкоштовному тарифі Google може використовувати надіслані фото для покращення своїх моделей. Якщо це неприйнятно (бланки містять імена працівників), у Google AI Studio можна підключити оплату (Billing). Тоді фото не використовуються, а одне фото коштує менше цента.

## Крок 2. Викласти програму на GitHub Pages (10 хвилин, один раз)

1. Зареєструйся на https://github.com (безкоштовно).
2. Натисни **+** вгорі праворуч → **New repository**. Назва: `skaner-kw`. Тип: **Public**. Натисни **Create repository**.
3. На сторінці репозиторію натисни **uploading an existing file**.
4. Перетягни туди **весь вміст** папки «Skaner KW»: файли `index.html`, `manifest.webmanifest`, `sw.js` і папки `icons` та `lib` (у `lib` має бути **два** файли .js). Натисни **Commit changes**.
5. Відкрий **Settings → Pages**. У полі **Branch** вибери `main` і `/ (root)`, потім натисни **Save**.
6. Через 1–2 хвилини там з'явиться посилання виду `https://ТВІЙ-ЛОГІН.github.io/skaner-kw/`.

Ключ Gemini **не потрапляє** на GitHub: він зберігається лише в телефоні.

## Крок 3. Встановити на телефон

1. Відкрий посилання з кроку 2 на телефоні.
   - **Android (Chrome):** меню ⋮ → **Додати на головний екран** / **Встановити застосунок**.
   - **iPhone (Safari):** кнопка «Поділитися» → **На початковий екран**.
2. Відкрий програму з іконки **KW**. Внизу розгорни **Налаштування**, встав ключ Gemini і натисни **Перевірити ключ**.

## Як користуватися

1. Натисни **«Сфотографувати бланк»** (відкриється камера) або **«З галереї»** (можна вибрати кілька фото).
2. Перевір картку: ім'я, суму й дату. Жовті та червоні позначки показують, на що звернути увагу. Наприклад, коли сума не збігається з полем RAZEM, людини немає у списку або людина вже є в таблиці.
3. Натисни **«Додати в таблицю»**. Якщо людина вже є в таблиці, її суми додаються, і біля імені з'являється позначка «2 KW», «3 KW» тощо.
4. Натисни на рядок, щоб його виправити. Хрестик ✕ видаляє рядок.
5. **«Вичистити»** видаляє всю таблицю, але спершу просить підтвердження.
6. **«Завантажити Excel + PDF»** зберігає два файли:
   - `wyplaty_РРРР-ММ-ДД.xlsx`: таблиця виплат;
   - `KW_РРРР-ММ-ДД.pdf`: усі фото бланків в одному PDF, по одному бланку на сторінку A4, у тому ж порядку, що й таблиця. Угорі кожної сторінки є прізвище, дата і номер бланка (наприклад, «KW 1/2»).

   На Android обидва файли потрапляють у «Завантаження». Якщо Chrome спитає «Дозволити завантаження кількох файлів?», натисни «Дозволити». На iPhone відкриється меню, де можна вибрати «Зберегти у Файли» для обох файлів одразу.

Таблиця, фото бланків і список працівників зберігаються в телефоні, у браузері. «Вичистити» видаляє і таблицю, і фото. Якщо очистити дані браузера, вони зникнуть. Тому Excel краще завантажувати щоразу після того, як закінчиш.

## Як оновити програму

Заміни `index.html` у репозиторії на GitHub: **Add file → Upload files**. Телефон підхопить нову версію під час наступного запуску з інтернетом.

Якщо Google колись вимкне модель, програма сама спробує іншу модель Gemini Flash. Назву моделі також можна змінити вручну в «Налаштуваннях».
